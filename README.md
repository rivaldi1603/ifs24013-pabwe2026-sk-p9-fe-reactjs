# Delcom Blog — Frontend SPA (ReactJS + Vite + Tailwind CSS)

Antarmuka multi-tier SPA (`Guest`, `Author`, `Admin`) untuk **Delcom Blog** dengan Toast UI Markdown Editor & Viewer, AI Blog Generator terintegrasi Live Search Engine, dan 100% Vitest code coverage.

## Menjalankan Frontend (Port 5174)
```bash
npm install
npm run dev
```
- Aplikasi Frontend: `http://localhost:5174` (reverse proxy `/api` ke `http://localhost:8081`)

## Pengujian Unit (100% Coverage)
```bash
npm test
```

## Build Produksi
```bash
npm run build
```
